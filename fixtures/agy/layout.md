# agy home layout

No agy home was available when the fixtures were sampled, so there is nothing to list. What is known (from earlier investigation, not
re-verified here):

- The deployment norm is one `HOME` per account (one agy home per profile).
- Local state holds no quota. The quota surface is the client's own `/usage` command
  (`usage-command.json`, `specs/sources.md` "agy"), which the exporter runs instead of reading the home.

Do not infer a layout from this file. Replace it with a names-only listing from a real agy home when one is available.
