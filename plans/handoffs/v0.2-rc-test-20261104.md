## Open risks and blockers

- **Provider balances.**
  - Type: decision. Owner: maintainer.
  - Impact: not built. A per-account `unit` label breaks the contract, and balances are money.
- **`-shm` writes with a live writer.**
  - Type: decision. Owner: maintainer.
  - Impact: a reader writes read-marks into the existing `-shm`, as every SQLite reader does. The alternative is to
    run the exporter as each DB's owner.
- **Idle memory.**
  - Type: risk. Owner: cloud lane.
  - Impact: above the 15 MB target in the cloud run; see the PR for the plateau measurement.
- **Codex credits outage shape.**
  - Type: question. Owner: on-prem.
  - Impact: unknown whether rollouts written during an outage carry `has_credits: false` or an error event.
- **Router health words.**
  - Type: question. Owner: on-prem.
  - Impact: `testStatus` words outside the known set read as failed and count a `parse` error.
